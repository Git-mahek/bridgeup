# Roadmap

## Vision

Adaptive, private, zero-install coding education that works on any school computer.

## Milestones

### Now

- [ ] Publish the federated-learning evaluation: accuracy versus privacy budget
- [ ] Teacher dashboard for classes
- [ ] Automated tests for the placement and progression logic

### Next

- [ ] More languages beyond Python
- [ ] Offline-first PWA
- [ ] Accessibility and screen-reader support for the code editor

### Later

- [ ] School-district deployments
- [ ] Content authoring tool
- [ ] Learning-outcome studies

## Where this can go

| Direction | Idea |
| --------- | ---- |
| **Startup** | Privacy-first adaptive coding education for schools. |
| **Publication** | The README describes a federated-learning engine with differential privacy; an evaluation paper is a natural next step. |
| **Patent** | Candidate area to review with an attorney before further public detail: test-gated adaptive progression combined with on-device federated updates. |

> **Intellectual property.** If you intend to patent a novel method, file before disclosing it publicly: public disclosure can bar patentability in many jurisdictions. Consult a patent attorney.
